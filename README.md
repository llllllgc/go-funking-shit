# 拉了么？Flutter 版

本地离线的排便记录应用，使用 Flutter / SQLite，同时支持 Android 与 iOS。

## 已实现

- 今天：今日次数、最近记录、修改、删除与近 7 天像素风圆柱厕纸卷统计（有记录时展开，今天带绿芽）
- 首页最近记录提供“按上次形态记录”快捷入口，复用上次 Bristol 形态并保留完整记录入口
- 观察卡支持 7 天 / 30 天切换：显示有记录的天数、记录总数、日均记录数和 Bristol 分布；样本较少时不作健康判断
- 记录：Bristol 01–07 形态选择，日常记录点选即存；修改记录时可调整日期、时间和形态，确认后保存；记录页提供按需打开的形态说明
- 可选细节：腹痛、腹胀、急迫、费力及最多 1000 字备注；填写细节后确认保存，返回时保护未保存的备注；快捷记录不会复制上一次的不适
- 每日提醒：默认关闭，可选时间、系统通知权限说明和测试通知；按设备当地时间安排，不显示健康记录内容。详见 [提醒行为与验收边界](docs/reminders.md)
- 帮助与关于：离线帮助、隐私与数据说明、版本更新、组件许可；读取实际安装版本并可复制反馈信息，不包含健康记录。发布资料见 [资料草案](docs/release/README.md)
- 设置与隐私：首页设置入口；可选系统身份验证应用锁、立即锁定、后台遮挡。锁定时保留草稿，但隐藏内容与可访问性节点；不提供跳过验证，应用锁不等于文件加密
- 数据管理：从历史页进入；完整 JSON 备份、7/30 天或全部 CSV 导出、导入预览与合并、输入“清空”后删除本机日志。CSV 默认不含备注/不适；重复和冲突导入均不覆盖本机内容
- 历史检索：本机关键词搜索，支持备注/形态/不适；7/30 天与自选日期、形态、不适可组合；保留本次使用的筛选条件，记录列表按需构建
- 历史：按日期倒序分组、右上角“＋补记”、月历入口、修改和带记录详情的删除确认
- 月历：点击首页近七日的任一纸卷进入对应日期；按自然月查看，周一开始、六行日期，支持翻月和年月跳转
- 回到今天：月历右上角使用像素小日历＋“今”字，长按显示含义；今天与选中日期分别标识
- 补记：历史入口默认昨天，月历入口带入选中日期；支持中文日期/时间选择，禁止未来时间，失败保留输入
- 小纸条：9 张离线知识卡，按主题筛选、展开阅读；首页只按最近形态关联观察主题。每张卡有具体来源、核对日期与打开/复制链接入口；就医提示区分立即求助和尽快联系医生，面向一般成年人科普
- 所有记录按实际发生时间同步到首页、历史和月历；SQLite v1/v2 自动升级至 v3，保留旧记录 ID、发生时间与更新时间，新增细节字段默认为空，应用锁默认关闭
- 记录使用本地 SQLite 持久化，无需账号；记录与科普正文离线可用，只有主动打开来源才调用外部浏览器联网；没有地图、AI 或旧 RPG 功能
- 删除后保留恢复提示，失败时可重试；关闭提示、离开页面或退出应用会结束本次恢复机会。详见 [删除与恢复](docs/record-recovery.md)；切换到今天或选择时间时会即时限制未来时刻
- 首页和知识库按全量记录中的最近一笔推荐纸条；历史页系统返回回到首页，平板内容列保持可读宽度
- 复用原版 Zpix 字体、SVG 和批准透明 PNG
- Android/iOS 应用名称、图标和启动画面
- 启动读取失败显示可重试页面；重试不清空数据库
- 320、375、414 与 768px 布局测试，新增 320px 双倍字号与横屏细节记录测试

## 运行

```powershell
flutter pub get
flutter run
```

Windows 可以构建和运行 Android：

```powershell
flutter build apk --debug
```

## Android Studio 打包

用 Android Studio 打开项目根目录（含 `pubspec.yaml`），通过 **Build → Flutter → Build APK** 打包，或在项目终端运行：

```powershell
flutter build apk --release
```

Release 需要单独的发布密钥。先把 `android/key.properties.example` 复制为本机的 `android/key.properties`，填写绝对密钥路径及对应值后再构建；未配置时会明确失败，不再借用调试签名。密钥、密码文件已由 Git 忽略，不能提交。安装包输出到 `build/app/outputs/flutter-apk/app-release.apk`。详情见 [发布签名说明](docs/release-signing.md)。

如果出现 `The SDK is not specified for modules lalema, lalema_android`，在 **File → Project Structure** 中给项目选择本机已安装的 Android SDK，并让两个模块的 **Module SDK** 继承 **Project SDK**。当前本机项目配置关联 Android API 36；更换电脑时需重新选择已注册的 SDK。修改 IDE 配置文件后，关闭并重新打开项目使其生效。

iOS 代码位于 `ios/`，最终编译、签名和真机测试需要 macOS、Xcode 与 Apple 开发者配置：

```bash
flutter build ios
```

```powershell
dart analyze --format machine .
flutter test
flutter build apk --debug
```

固定验证环境：Flutter `3.44.9` / Dart `3.12.2`。CI 执行格式检查、静态分析、单元/界面/真实 SQLite 测试，以及 Android Debug / iOS 模拟器构建。SQLite 测试使用独立临时数据库，不读写用户记录。

2026-10-09 已在 macOS 上实际运行分析与回归，并完成 iOS 模拟器构建/启动。详见 [发布准备与验收](docs/release-readiness.md)，包含尚未完成的发布条件。iOS 最低部署版本为 15.0（当前 Xcode 27 构建要求）。

删除应用可能一并删除本地记录；系统设备备份是否包含应用数据取决于平台与设备设置。现在可从“历史 → 备份、导出与恢复”保存完整 JSON 备份；导出文件未加密，请保存在可信位置。CSV 仅用于阅读，不能导入。当前版本仍待完整真机与分发验收，不能称为正式发布版本。

当前开发版本：`1.11.1+14`。交互草图位于 `tool/prototypes/`，用于设计留档，不会打包进 App。真实 Flutter 页面截图位于 `tool/captures/`，使用虚构演示记录。
