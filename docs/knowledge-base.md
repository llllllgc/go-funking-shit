# 小纸条知识库

本应用随包提供 9 张离线科普卡，面向一般成年人，帮助整理观察，不诊断、打分或代替就医。源数据为 `lib/data/knowledge_base.dart`，逐项依据与修改记录见 [内容核对表](knowledge-content-audit.md)。

## 阅读与来源

- 首页根据最近一次记录的形态，关联“偏硬时记录哪些情况”“如何理解形态”“稀便时记录哪些情况”。不根据单次记录推荐饮食干预或判断疾病。
- 知识库按主题换行排列，支持“阅读这张”跳到对应正文；“何时需要就医”直接打开相关提示。
- 正文独立于展开按钮，读屏可以访问细节和每个来源操作。来源显示机构、具体文章主题、核对日期，原文为英文。
- 打开原文使用外部浏览器，需要联网；只传递随包来源 URL，不附带日志或症状。浏览器不能打开时保留正文并提供复制链接及可选择的完整 URL。
- “内容核对”是对来源和表述的编辑检查，不是医学认证，也不是原网站最近更新日期。当前核对日期为 2026-10-09。

## 内容规则

1. 每张卡必须列出支持其具体表述的来源，不能只写机构名称。医疗判断依据优先使用公共卫生机构或医院患者资料。
2. Bristol 形态只作外观记录。不能用单次形态、漏记或日期间隔推断诊断、食物因果关系或个人健康评分。
3. 食物可能改色的说明必须同时保留不能自行排除出血的提醒。不得建议先等几天观察食物再处理便血或黑色柏油样便。
4. 紧急出血/休克迹象的求助提示，与其他需尽快联系医生的变化分开；不把英国、美国急救号码硬编码成所有地区通用号码。
5. 成人腹泻的时长说明不能覆盖儿童或更高风险人群，也不能让有警示症状者等待够天数。
6. 不提供药品剂量、自行停药方案、固定饮水杯数或强制如厕频率。后续修改需重新核对引用与适用人群。

## 验证边界

源码与交互测试验证来源完整性、打开方式、复制内容、错误恢复、主题选择及小屏/读屏可达性；这些测试不能自动证明医学正确性。内容表述另按核对表逐项对照原文。该版本未接受独立临床专家审核，不宣称具备诊断或治疗能力。
