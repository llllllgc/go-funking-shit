## 本轮实施顺序

1. 复用已安装的 Flutter 3.44.9 / Dart 3.12.2，恢复依赖并运行现有分析与测试。
2. 修复真实失败项，统一统计、删除/恢复与快捷记录文案，验证小屏和大字。
3. 添加可选备注/不适与 SQLite 升级；测试从旧库迁移和完整增删改恢复。
4. 为启动读取失败提供明确重试流程，建立 CI，再进行平台构建与视觉验收。
5. 记录本轮实际证据和剩余发布条件；继续完成数据管理、隐私、提醒及发布交付。
