## 1.6.0 数据管理实现与待验收项

- JSON 备份保留全部记录 ID、毫秒时间戳、Bristol 类型、备注与不适；编解码在后台 isolate 运行。
- 读取文件有 32 MB / 100000 条上限，校验格式版本、字段、类型、记录数、时间范围与重复编号。损坏或不兼容的文件不进入写入阶段。
- 导入前展示新增/重复/冲突数；仅添加缺失编号。同编号内容不同保留本机版本，不自动覆盖。SQLite 批量导入在事务内重算计划；真实触发器注入的中途失败证明整批回滚。
- CSV 可选 7 天 / 30 天 / 全部，默认仅时间与形态；用户勾选后才含细节。包含 UTF-8 BOM、引号/换行转义和公式前缀处理。CSV 是阅读格式，不是恢复格式。
- 清空操作需要输入“清空”；清空成功后旧的删除恢复缓存失效。不会删除已导出的文件或系统备份。
- 系统文件保存/选择使用 [file_picker 的移动平台 API](https://pub.dev/packages/file_picker)。iOS 插件的全局清理会删除整个应用临时目录，因此本应用改为仅清理本次操作的临时文件，保留原文件和无关文件。适配层测试覆盖这项边界。
- 新增测试使用虚构记录、临时数据库和文件选择器替身；替身通过不代表系统文档选择器、iCloud/其他云盘和真机权限体验已经验收。
- 本地 HTTPS 连接在本轮中途失败（GitHub、Maven、pub.dev 均失败）。Android 新插件依赖下载及推送需要网络恢复；没有关闭 TLS 校验或改用不可信镜像。
