# 版本更新

更新日期：2026-10-09

## 1.11.1 · 提醒授权与备份反馈

修复首次允许通知后提醒仍关闭的问题：授权完成后等待应用恢复前台，再完成本次开启；离开应用或锁定后的旧操作仍会取消。补充系统通知设置指引，改进重复备份的导入提示。

## 1.11.0 · 帮助与关于

增加离线使用帮助、完整数据处理说明、实际安装版本读取与版本信息复制。补充开源组件许可和资源出处入口，发布者信息由发布资料统一管理。

## 1.10.0 · 可核对的科普

9 张科普卡补齐具体来源与核对日期，支持打开和复制链接。完善就医提示、正文读屏语义与大字布局，首页关联观察主题。

## 1.9.0 · 可选每日提醒

新增默认关闭的每日提醒、时间选择、通知状态与测试提醒；通知不显示健康记录内容。

## 1.8.0–1.8.1 · 隐私与恢复

新增系统身份验证应用锁、后台遮挡，并完善单条删除后的失败重试及恢复提示关闭行为。

## 1.6.0–1.7.0 · 数据管理与查找

新增 JSON 备份恢复、CSV 导出、清空确认、历史关键词和组合筛选，并建立双端验证流程。
