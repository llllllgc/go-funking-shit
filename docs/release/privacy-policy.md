## 记录由你掌握

拉了么？是一款本地排便记录工具。你可以记录形态、发生时间，以及自愿填写的备注和不适信息；内容用于自己回顾和与专业人员沟通，不用于诊断或治疗。

应用无需账号，不包含广告、行为分析或自动上传记录的服务。应用不提供开发者服务器端备份；若本机记录丢失且没有有效备份，开发者无法恢复。

## 本机保存哪些信息

记录包含形态、发生时间、更新时间、记录编号，以及你主动填写的备注和腹痛、腹胀、急迫或费力等选项，保存在设备的应用数据中。

应用还保存应用锁开关、每日提醒的开关和时间，以及调度提醒所需的状态。Android 会按需要保存通知是否申请过、下一次提醒时间和最近一次提醒日期。当前会话的搜索筛选和未保存表单用于界面操作，不会上传。

应用不读取或保存你的系统密码、指纹或面容数据，只接收系统身份验证的结果。

## 权限与可选功能

每日提醒默认关闭。你主动开启时才申请系统通知权限；拒绝不会影响记录功能。通知仅显示通用提示，不展示记录次数、形态、备注或不适。你可以随时在应用内关闭提醒，也可以在系统设置中管理通知。

应用锁由你选择开启，使用设备现有的验证方式。它限制应用内访问，不会加密数据库、导出文件或系统备份。其他人掌握设备解锁凭据或设备被破解时，应用锁不能提供相应保护。

备份保存和导入通过系统文件选择器完成，由你选择文件和保存位置。应用不要求通讯录、定位、相机或麦克风权限来完成日常记录。

## 备份、导入与第三方服务

只有你主动操作时，应用才会把记录写入所选位置的 JSON 或 CSV 文件。JSON 包含完整记录，CSV 仅含所选范围和字段。导出文件未加密，请保存在可信位置，分享前检查内容。

选择云盘等文件服务时，该服务按其自己的规则处理文件。设备或云端系统备份是否包含应用数据，取决于平台和你的设置；请同时检查相关备份服务。

导入和导出可能产生临时文件。应用会在操作结束后尽力清理本次操作的缓存；已导出文件、系统备份和文件服务的副本由你及相应服务管理。

打开科普原文会进入外部浏览器并使用网络。应用只传递公开来源网址，不在链接中附带你的记录；原网站和浏览器按各自规则处理访问。

## 保存、删除与恢复

本机记录会保留至你删除或清空，或系统移除相关应用数据。卸载应用可能删除本机记录，请先保存需要保留的 JSON 备份。

单条删除后，恢复提示存活期间会在内存里保留原记录；恢复成功、关闭提示、离开页面、下一次删除替换提示或退出应用后，会结束这次恢复机会。恢复失败时可在原提示中重试。

“清空本机记录”需要输入确认，清除当前日志和应用内的删除恢复缓存，不能直接撤销。它不会删除你导出的文件或系统备份，也不会改变应用锁和提醒偏好。已有有效 JSON 备份可由你重新导入。

若需删除应用以外的副本，请同时检查导出位置、云盘和系统备份。应用不承诺设备存储层面的不可恢复擦除。

## 版本信息与问题反馈

“复制版本信息”仅复制应用名称、版本、构建号和平台名称，不包含你的记录、设备标识、备份文件或系统验证信息。复制后是否分享，由你决定。

反馈问题时可以提供操作步骤、期望结果和实际结果。请勿公开发送包含个人记录的备份文件或未经处理的截图。

## 使用范围与说明更新

应用中的科普以一般成年人为主要读者，不提供儿童专用医疗方案。紧急不适应优先寻求当地医疗帮助。

数据处理方式发生变化时，会随相应版本更新本说明。你可以在“帮助与关于”中离线查看当前说明的更新日期。
