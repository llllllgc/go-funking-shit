# 商店资料草案

这是可供发布者审核的文案和事实清单，不代表已提交商店、已获得审核批准或已完成实机验收。

## 中文名称与简介

应用名称：拉了么？

App Store 副标题：本地记录、回顾和备份

Google Play 简短说明：无需账号，记录形态与感受，回顾日常变化并自主备份。

## 完整介绍

拉了么？是一款本地排便记录工具，帮助你记下每次发生的时间、形态与感受，按自己的节奏回顾。

快速记录：日常记录选择形态即可保存；需要时添加备注和不适信息，也可以补记或修改过去的记录。

回顾与查找：通过日历、关键词、日期和形态筛选找到记录，查看近 7 天或 30 天的记录次数与形态分布。漏记不会被当作没有排便。

自己保管数据：无需账号，记录保存在设备上。可导出完整 JSON 备份，在另一台设备导入；也可以按范围导出 CSV。导出文件未加密，请妥善保管。

可选隐私保护：应用锁使用设备现有的系统验证方式，配合后台遮挡。应用锁限制应用内访问，不等于数据库或备份加密。

温和提醒：每日提醒默认关闭，可选择时间和管理通知权限。提醒不显示健康记录内容；实际送达可能受系统省电、专注模式等设置影响。

可核对的科普：离线阅读形态、习惯等主题，展开查看来源和核对日期。打开原文需要联网。

本应用用于手动记录和一般成年人科普，不提供诊断或治疗建议。身体不适时请咨询专业医护人员，紧急情况优先寻求当地医疗帮助。

## 审核备注草案

- 不需要登录或演示账号。首次打开不会请求通知或生物识别权限。
- 首页中间“记录”进入形态选择，日常记录点击形态即可保存；添加细节后需确认保存。
- 历史页提供筛选、补记及备份/恢复入口。清空数据需要输入“清空”。
- 设置页提供可选应用锁和每日提醒；两者依赖相应设备能力或系统权限，拒绝通知后其他记录功能仍可使用。
- “帮助与关于”可离线查看使用帮助和数据处理说明，版本号来自安装包。
- 科普来源、字体说明以及配置后的支持/政策地址会在外部浏览器或邮件应用中打开；应用不自动发送反馈或附带健康记录。
- 测试时请使用合成记录。没有声明医疗诊断、疾病预测或健康评分功能。
