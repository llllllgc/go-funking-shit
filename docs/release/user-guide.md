# 使用帮助

更新日期：2026-10-09

## 怎样快速记一条？

点击底部“记录”，选择最接近的形态即可保存。需要备注或不适信息时，先展开“添加细节（可选）”，填写并选择形态后点击保存。

首页的“按上次形态记录”只沿用形态，不会复制旧的备注或不适信息。

## 如何补记和修改？

历史页的“＋补记”默认选择昨天，也可以从月历选择过去的日期再补记。修改已有记录时可以调整发生时间、形态和细节。

不能选择尚未发生的时间。日期异常时，先检查设备日期与时区，再核对历史筛选条件。

## 删除后还能恢复吗？

删除后可在提示条中恢复原记录。恢复失败时，保持提示打开并点击“重试恢复”。

关闭提示、离开页面、下一次删除替换提示或退出应用，会结束这次恢复机会；应用没有跨重启回收站。如有有效 JSON 备份，可以重新导入。

## 怎样备份和换机？

从历史页或设置进入“备份、导出与恢复”，选择“保存 JSON 备份”，保存到你信任的位置。换机后安装应用，选择 JSON 备份并核对导入预览。

相同记录会跳过，编号相同而内容不同的记录保留本机版本，不会自动覆盖。请保留原备份，方便核对。CSV 便于阅读或分享，不能用于恢复。

升级或卸载前建议先备份。应用没有开发者服务器副本，未备份的数据无法由开发者恢复。

## 提醒没有出现怎么办？

每日提醒默认关闭，需要你选择开启并允许系统通知。检查应用开关、系统通知设置、专注模式和省电限制；系统可能延后或静音通知。

允许通知后，可以使用“发送测试提醒”检查显示方式。Android 被强制停止后，需要重新打开应用；回到应用也会重新检查提醒状态。

## 应用锁无法解开怎么办？

应用锁使用设备现有的面容、指纹或锁屏密码，没有另设一个应用密码。先确认设备的系统验证方式能正常使用。

验证失败不会清空记录，也没有跳过验证入口。需要先恢复设备验证能力；不要仅为排查问题直接卸载应用，以免失去未备份的数据。

## 为什么今天或历史里没有记录？

没有记录只说明尚未记下，不代表没有排便。补记会归入所选的发生日期。

先查看设备日期与时区，再检查关键词、日期、形态和不适筛选。清除筛选只改变显示范围，不会删除日志。

## 小纸条能判断身体状况吗？

小纸条帮助整理观察，不能替代诊断或治疗。首页只按最近形态关联主题，不计算健康分数或判断食物因果关系。

展开正文可查看资料来源、核对日期，并打开或复制原文链接。就医提示位于“何时需要就医”入口；紧急不适请优先寻求当地医疗帮助。

## 反馈问题时提供什么？

在“帮助与关于”复制版本信息，再说明操作步骤、期望结果和实际结果。无需发送完整健康记录。

如果需要截图，请先处理个人信息；不要把 JSON 备份或含个人记录的截图直接贴到公开反馈页面。
